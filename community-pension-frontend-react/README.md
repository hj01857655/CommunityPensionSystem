# Community Pension System - React Frontend

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

React 19 + Vite 8 + Ant Design 6 + Tailwind CSS 4 + Zustand + React Router 7 + TypeScript 6

## Commands

```bash
npm run dev          # Start dev server
npm run build        # Build for production
npm run type-check   # Type checking
npm run lint         # Lint code
npm run format       # Format code
```
